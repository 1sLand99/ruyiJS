WHY RUYIJS

Firefox internals, not a browser impersonation.

Headless Chrome ships a whole GPU-rendering, window-managing process that vendors have spent years learning to detect. ruyiJS embeds only the internals that matter for automation — and executes a site's JavaScript exactly as Firefox would.

Authentic engine

Genuine SpiderMonkey (Firefox 158) and the Necko network stack — the same bytecode, timers, and TLS fingerprint a real browser emits.

Configurable fingerprint

Set Navigator, Screen, viewport, timezone, and locale through one validated profile surface before the first page script runs.

Per-context isolation

Each Context is its own process with a persistent JavaScript world and its own proxy, so sessions stay isolated and reproducible.

Deterministic clock

Drive timers with a logical clock for perfectly reproducible runs, or switch to the system clock for live network work.

Native fetch over Necko

In-page fetch and XHR ride real HTTP/1.1, 2 and 3. Serve captured responses with put_resource() to replay whole flows offline.

Python ↔ JS bridge

Pass data with set(), call JS functions from Python, and expose Python callbacks to the running script. Workers, Service Workers, and iframes included.

PROVEN IN THE FIELD

Verification systems it defeats.

Every example drives the site's own JavaScript to produce the parameters it demands, then completes the flow end to end. Ships runnable in the package: python -m ruyijs.examples <name>.

Strictly prohibited for any unlawful use — provided solely for research into a new generation of AI browsers. Live results depend on current network conditions and each site's present responses.

FROM PYTHON

Scriptable, with no window in sight.

Call Python from JavaScript
with Context() as ctx:
    ctx.expose(lambda a, b: a + b, "add")
    print(ctx.eval("add(20, 22)"))  # 42
Fetch through a per-context proxy
with Context(proxy="http://127.0.0.1:7890") as ctx:
    ctx.load_page("https://example.com/", "")
    ctx.eval("fetch('/api').then(r => r.json())")
    ctx.advance(25)  # drive the event loop
Load a page offline and query the DOM
with Context() as ctx:
    ctx.put_resource(".../app.js", "window.answer=42")
    ctx.load_page(url, "<script src=/app.js></script>")
    ctx.eval("document.title")
Catch JavaScript errors as Python exceptions
from ruyijs import Context, JSError
try:
    ctx.eval("throw new TypeError('bad')")
except JSError as e:
    print(e.name, e.stack)
